# Часы Сингулярности

Интерактивная модель, которая из одной экстраполяции — горизонта автономных
задач METR — выводит два обратных отсчёта: до сингулярности и до катастрофы по
трёхуровневой шкале. Плюс рейтинг стран, панель наблюдаемых триггеров и
дисклеймер, который никто не прочитает, но который обязан быть.

Ключевая мысль сервиса: **дата не является результатом. Результатом является
чувствительность даты к допущениям.** Если ползунок «отказ контроля» двигает
глобальную дату на сорок лет, а «время удвоения» — на пять, спорить надо про
первое.

## Статус

**Опубликовано: [aiapocalypse.now](https://aiapocalypse.now)** — 7 страниц,
английский, OG-картинки работают, axe не находит нарушений, горизонтальной
прокрутки на ширине 390 нет.

V0 закрыт: M0 каркас, M1 ядро с паритетным тестом против прототипа и кодек
сценария, M2 разделы и графики, M3 шаринг, OG и режим сравнения, M5a страны.

**Сайт одноязычный, английский.** Это отход от ТЗ §12, требовавшего две
локали, — решение владельца от 19 августа 2026. Механизм локализации оставлен
целиком: форматирование чисел, дат и склонений нужно и при одном языке,
а добавление второго сводится к словарю и записи в `locales.ts`. Русские
страницы жили под `/ru/`, английские под `/en/`; оба префикса уводят
постоянным редиректом на новые адреса в корне.

Осталось одно, и это не код: **страновой датасет — черновик.** Баллы
расставлены как заготовка под структуру рейтинга и не выверены по AI Index,
Tortoise и OECD. Интерфейс об этом предупреждает красным блоком, а связь
с моделью риска выключена по умолчанию. Заменить числа и проставить
`checkedAt` в `packages/data/datasets/countries.json`.

Живых данных нет по построению: M4 (лента, инциденты, котировки,
автоматическое смещение якоря) отложен за пределы V0 — см.
[ADR-0001](docs/adr/0001-stack.md).

## Как запустить

```bash
pnpm install
pnpm check     # линтер, границы пакетов, типы, тесты
pnpm dev       # сайт на localhost
```

Отдельные проверки: `pnpm lint`, `pnpm typecheck`, `pnpm test`,
`pnpm check:core-deps`, `pnpm check:generated`.

Палитра правится только в `packages/ui/src/tokens.ts`; CSS генерируется
командой `pnpm gen:css`, и CI падает, если файл разошёлся с источником.

Деплой — Netlify, git auto-deploy из `main` плюс Deploy Preview на каждый
pull request. Настройки сборки лежат в `netlify.toml`; в GitHub Actions
деплоя нет, там только проверки.

## Порядок работ

M0 каркас → M1 ядро с golden-тестами → M2 графики → M3 шаринг → M5a страны →
M5b — язык. M4 (живые данные) — после V0.

Порядок жёсткий. Главная ловушка проекта — сделать красивый график и потом
подгонять под него модель, поэтому **интерфейс не начинается, пока golden-тесты
ядра не зелёные.**
