# Часы Сингулярности

Интерактивная модель, которая из одной экстраполяции — горизонта автономных
задач METR — выводит два обратных отсчёта: до сингулярности и до катастрофы по
трёхуровневой шкале. Плюс рейтинг стран, панель наблюдаемых триггеров и
дисклеймер, который никто не прочитает, но который обязан быть.

Ключевая мысль сервиса: **дата не является результатом. Результатом является
чувствительность даты к допущениям.** Если ползунок «отказ контроля» двигает
глобальную дату на сорок лет, а «время удвоения» — на пять, спорить надо про
первое.

## Статус

Проектирование закончено, кода пока нет. Решения приняты, можно начинать M0.

**V0 идёт без бэкенда** ([ADR-0001](docs/adr/0001-stack.md)). Это убирает из
объёма короткие ссылки, голосование по триггерам и живую ленту с автоматическим
смещением якоря; всё остальное, включая страновой рейтинг и OG-картинки,
работает на статике.

## Порядок работ

M0 каркас → M1 ядро с golden-тестами → M2 графики → M3 шаринг → M5a страны →
M5b английская версия. M4 (живые данные) — после V0.

Порядок жёсткий. Главная ловушка проекта — сделать красивый график и потом
подгонять под него модель, поэтому **интерфейс не начинается, пока golden-тесты
ядра не зелёные.**
